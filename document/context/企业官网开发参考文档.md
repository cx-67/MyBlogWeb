## 一、技术选型与可复用性评估

### 1.1 当前技术栈

| 技术 | 版本 | 用途 | 企业官网复用度 |
|------|------|------|---------------|
| Astro | ^4.16.18 | 静态站点生成 | ★★★★★ 完全复用 |
| TypeScript | strict 模式 | 类型安全 | ★★★★★ |
| 原生 CSS + CSS 变量 | — | 样式系统 | ★★★★☆（需调整配色） |
| @astrojs/sitemap | ^3.2.1 | SEO 站点地图 | ★★★★★ |
| sharp | ^0.33.5 | 图片优化 | ★★★★★ |

### 1.2 为什么 Astro 适合企业官网

- **零 JS 默认输出**：构建产物是纯 HTML，首屏极快，SEO 友好
- **岛屿架构**：只在需要交互的组件加载 JS（如导航菜单、标签切换）
- **内容集合**：天然适合"产品介绍 / 新闻动态 / 案例展示"等内容驱动型官网
- **Markdown 驱动**：非技术人员也能通过写 Markdown 更新官网内容
- **静态部署**：可部署到 GitHub Pages / Vercel / Netlify / 对象存储，运维成本极低

### 1.3 企业官网可能需要额外引入

| 需求 | 推荐方案 | 源项目是否有 |
|------|----------|-------------|
| 表单提交 / 联系我们 | Astro API Routes + 邮件服务（如 Resend） | ❌ 需新增 |
| 多语言 i18n | Astro i18n routing | ❌ 需新增 |
| CMS 后台管理 | Astro DB / Tina CMS / Decap CMS | ❌ 需新增 |
| 站内搜索 | Pagefind（静态站搜索） | ❌ 需新增 |
| 数据可视化 | Chart.js / ECharts | ❌ 需新增 |

## 三、设计系统（Design Tokens）

> 文件：`src/styles/global.css`
> 这是最核心的可复用资产，企业官网只需替换配色变量即可获得统一的视觉语言。

### 3.1 CSS 变量分层架构

源项目采用**单文件设计令牌**模式，所有设计决策集中在一个文件：

```css
:root {
  /* 1. 配色 */
  --color-bg, --color-bg-soft, --color-card
  --color-text, --color-text-soft, --color-text-muted
  --color-accent, --color-pink, --color-mint ...
  --color-border, --color-border-strong
  --shadow-soft, --shadow-hover, --shadow-card

  /* 2. 圆角 */
  --radius-sm: 10px; --radius-md: 16px; --radius-lg: 20px; --radius-pill: 999px;

  /* 3. 间距 */
  --space-1 ~ --space-24（4px 步进）

  /* 4. 字体 */
  --font-sans, --font-display, --font-mono

  /* 5. 布局 */
  --max-width: 920px; --max-width-narrow: 680px;

  /* 6. 过渡 */
  --transition: 0.25s ease;
}
```

**企业官网复用方式**：复制 `global.css`，只改 `:root` 里的色值，其余样式自动生效。

### 3.2 当前配色（莫兰迪温馨系）→ 企业官网适配

源项目用莫兰迪低饱和色，企业官网建议根据行业调整：

| 企业类型 | 建议主色 | 建议背景 | 建议强调 |
|----------|----------|----------|----------|
| 科技/互联网 | 深蓝 `#2563EB` | 纯白 `#FFFFFF` | 青色 `#06B6D4` |
| 金融/法律 | 深绿 `#0F5132` | 米白 `#FDFBF7` | 金色 `#B8860B` |
| 医疗/健康 | 青绿 `#0D9488` | 纯白 | 柔粉 `#F43F5E` |
| 教育 | 靛蓝 `#4F46E5` | 米白 | 橙黄 `#F59E0B` |
| 制造/工业 | 钢灰 `#475569` | 浅灰 `#F8FAFC` | 安全橙 `#EA580C` |

> 当前莫兰迪色系变量值（`#FDFBF7` 背景、`#4A403A` 文字）适合温和型品牌，可直接保留。

### 3.3 排版系统

```css
/* 字号使用 clamp() 实现流式响应 */
h1 { font-size: clamp(1.8rem, 4.5vw, 2.4rem); }
h2 { font-size: clamp(1.4rem, 3.5vw, 1.7rem); }
h3 { font-size: 1.15rem; }
body { font-size: 15px; line-height: 1.75; }  /* 移动端 14px */
```

**企业官网建议**：正文行高 `1.75` 对中文非常友好，直接复用。

### 3.4 响应式断点

源项目只用一个断点：`@media (max-width: 640px)`，在该断点下：
- 缩小 `--space-12/16/20`
- 导航折叠为汉堡菜单
- 卡片网格自动从 2 列变 1 列（`grid-2` 用 `auto-fill, minmax(320px, 1fr)`）

**企业官网建议**：如果需要平板适配，可增加 `768px` 断点。

## 四、可复用组件清单

### 4.1 直接复用（无需改动）

| 组件 | 文件 | 功能 | 企业官网用途 |
|------|------|------|-------------|
| **ScrollReveal** | `ScrollReveal.astro` | Intersection Observer 滚动渐入 | 所有页面区块动画 |
| **BaseLayout** | `BaseLayout.astro` | 全局布局骨架 | 直接复用 |
| **404 页面** | `404.astro` | 友好的 404 | 直接复用 |

### 4.2 改造后复用

#### ① Header（顶部导航）— `Header.astro`

**核心特性**：
- `position: sticky; top: 0` 吸顶
- `backdrop-filter: blur(12px)` 毛玻璃效果（需半透明背景 `rgba(255,255,255,0.8)`）
- 当前页高亮逻辑（`isActive` 函数，支持 base 路径）
- 移动端汉堡菜单（`<640px` 折叠）

**企业官网改造点**：
```ts
// 导航项改为企业官网结构
const navItems = [
  { href: '', label: '首页' },
  { href: 'products', label: '产品' },
  { href: 'solutions', label: '解决方案' },
  { href: 'cases', label: '客户案例' },
  { href: 'news', label: '新闻动态' },
  { href: 'about', label: '关于我们' },
  { href: 'contact', label: '联系我们' },
];
```
- 可加二级下拉菜单（产品分类）
- 可加"登录/注册"按钮在右侧

#### ② Footer（页脚）— `Footer.astro`

**企业官网改造点**：
- 左侧：公司全称、备案号（如 `苏ICP备XXXXXX号`）、版权
- 右侧：导航链接、社交媒体（微信/微博/LinkedIn）
- 可增加多列链接区（产品/资源/公司/法律）

#### ③ ProjectCard → ProductCard（产品卡片）

**源项目核心特性**：
- `display: flex; flex-direction: column` 卡片布局
- `::before` 伪元素做顶部光晕渐变线（hover 时淡入）
- `transform: translateY(-3px)` 悬停上浮
- `box-shadow` 悬停加深带品牌色调
- 标签用 `tagClass()` 统一颜色
- `-webkit-line-clamp` 多行文本截断

**企业官网改造**：把 `project` 集合换成 `products`，字段调整为 `name / tagline / category / icon`。

#### ④ PostCard → NewsCard（新闻卡片）

同理，把 `posts` 换成 `news`，加 `publishDate / category / author`。

#### ⑤ Tags（标签系统）— `Tags.astro` + `lib/tags.ts`

**这是源项目最有价值的可复用系统**：

- `lib/tags.ts` 提供 **tag 名称 → 颜色** 的确定性映射（不依赖位置）
- 支持交互式筛选（`?tag=xxx` URL 参数）
- 未在映射表中的 tag 用 djb2 哈希回退

**企业官网用途**：产品分类标签、新闻分类、案例行业标签，全部可复用这套颜色统一机制。

```ts
// 改造 TAG_COLOR_MAP 为企业业务语义
const TAG_COLOR_MAP = {
  '云计算': 1, '大数据': 1, 'AI': 1,        // 核心业务 → 粉
  'Java': 2, 'Python': 2, 'Go': 2,          // 技术 → 绿
  '金融': 3, '零售': 3, '制造': 3,           // 行业 → 蓝
  // ...
};
```

### 4.3 按需复用（视觉装饰类）

| 组件 | 文件 | 企业官网建议 |
|------|------|-------------|
| **StarBackground** | `StarBackground.astro` | 仅适合创意/文化类企业；科技企业建议替换为几何线条或留白 |
| **Typewriter** | `Typewriter.astro` | 首页 Hero 标语可用；正式企业建议慎用 |
| **ParticleBackground** | `ParticleBackground.astro` | 已弃用（被 StarBackground 替代），不建议复用 |

## 五、页面结构与布局模式

### 5.1 通用页面骨架

```astro
<BaseLayout title="页面标题" description="页面描述">
  <div class="container">
    <div class="page-head fade-up">
      <p class="eyebrow">分类标签</p>      <!-- 小标题 -->
      <h1>页面主标题</h1>
      <p class="section-desc">页面描述...</p>
    </div>
    <!-- 内容区 -->
  </div>
</BaseLayout>
```

**可复用的 CSS 类**（定义在 global.css）：
- `.container` — 居中容器，`max-width: 920px`
- `.container-narrow` — 窄容器，`680px`（适合文章正文）
- `.eyebrow` — 小标题（大写字母 + 字间距）
- `.section-title` / `.section-desc`
- `.divider` — 渐变分隔线
- `.grid` / `.grid-2` — 响应式网格（`minmax(320px, 1fr)`）
- `.btn` / `.btn-primary` / `.btn-soft` — 胶囊按钮
- `.fade-up` — 入场动画

### 5.2 首页（Hero 区）模式

源项目首页 Hero 结构值得参考：
```
Hero Section（带动态背景）
  ├── 主标题（打字机效果 + 副标题缩小变灰）
  ├── 描述文案
  ├── 行动号召按钮组（主按钮 + 次按钮）
  └── （下方）技术栈标签云
```

**企业官网 Hero 建议**：
- 主标题用公司 Slogan
- 副标题用一句话定位
- 主按钮："免费试用 / 预约演示"，次按钮："了解更多"
- 下方可放客户 Logo 墙（信任背书）

### 5.3 关于页的标签页（Tabs）模式 — `about.astro`

源项目的关于页用了**纯原生 JS 标签页切换**，非常优雅：

```html
<nav class="tabs" role="tablist">
  <button class="tab active" data-tab="overview">概览</button>
  <button class="tab" data-tab="timeline">经历</button>
  ...
</nav>
<div class="tab-panels">
  <section class="tab-panel active" data-panel="overview">...</section>
  <section class="tab-panel" data-panel="timeline" hidden>...</section>
</div>
```

**核心 JS 逻辑**：
- 点击切换 `active` 类 + `hidden` 属性
- `history.replaceState` 更新 URL hash，刷新可保留状态
- 支持 ARIA（`role="tab"` / `aria-selected`）

**企业官网用途**：产品详情页的"功能 / 规格 / 文档 / 常见问题"标签页。

### 5.4 时间线（Timeline）模式

源项目关于页的 `.timeline` 组件（带左侧竖线 + 圆点）非常适合：
- 企业发展历程
- 项目交付流程
- 团队成长路线

### 5.5 列表页 + 详情页模式

```
列表页 (index.astro)
  ├── 标签云（点击筛选）
  ├── 计数提示（"共 N 个"）
  └── 卡片网格

  ├── 返回链接
```

## 六、内容集合（Content Collections）模式

> 文件：`src/content/config.ts`
> 这是 Astro 最适合企业官网的特性——**用 Zod 定义内容 Schema，Markdown 写内容，构建时校验**。

### 6.1 源项目 Schema 示例

```ts
const projects = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    cover: z.string().optional(),
    tags: z.array(z.string()).default([]),
    category: z.string().default('fullstack'),
    role: z.string().default('独立开发'),
    date: z.coerce.date(),
    featured: z.boolean().default(false),
    liveUrl: z.string().url().optional(),
    repoUrl: z.string().url().optional(),
    documents: z.array(z.object({ name: z.string(), path: z.string() })).default([]),
    externalDocs: z.array(z.object({ name: z.string(), url: z.string().url() })).default([]),
    order: z.number().default(0),
  }),
});
```

### 6.2 企业官网建议 Schema

```ts
// 产品集合
const products = defineCollection({
  type: 'content',
  schema: z.object({
    name: z.string(),
    tagline: z.string(),                    // 一句话定位
    description: z.string(),
    icon: z.string().optional(),            // 产品图标
    cover: z.string().optional(),
    category: z.string(),                   // 产品线分类
    tags: z.array(z.string()).default([]),
    features: z.array(z.string()).default([]),   // 核心功能点
    order: z.number().default(0),
    featured: z.boolean().default(false),
  }),
});

// 新闻集合
const news = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    summary: z.string(),
    date: z.coerce.date(),
    category: z.enum(['公司动态', '行业资讯', '产品更新']),
    author: z.string().optional(),
    cover: z.string().optional(),
    tags: z.array(z.string()).default([]),
    draft: z.boolean().default(false),
  }),
});

// 客户案例
const cases = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    client: z.string(),                     // 客户名称
    industry: z.string(),                   // 行业
    challenge: z.string(),                  // 痛点
    solution: z.string(),                   // 解决方案
    results: z.array(z.object({             // 成果数据
      metric: z.string(),
      value: z.string(),
    })).default([]),
    date: z.coerce.date(),
    cover: z.string().optional(),
    tags: z.array(z.string()).default([]),
  }),
});
```

## 七、动态效果与交互

### 7.1 滚动渐入动画 — `ScrollReveal.astro`

**最推荐复用的组件**。基于 Intersection Observer，零依赖：

```html
<!-- 用法：给元素加 reveal 类 -->
<div class="reveal">默认从下方淡入</div>
<div class="reveal-left">从左侧滑入</div>
<div class="reveal-right">从右侧滑入</div>
<div class="reveal-scale">缩放淡入</div>

<!-- 错开延迟 -->
<div class="reveal reveal-delay-1">0.1s 延迟</div>
<div class="reveal reveal-delay-2">0.2s 延迟</div>
```

**特性**：
- `threshold: 0.1` + `rootMargin: '0px 0px -40px 0px'` 提前触发
- `observer.unobserve()` 只触发一次
- 支持 `prefers-reduced-motion`

## 八、部署与路径处理

### 8.1 base 路径处理（关键！）

源项目部署在 GitHub Pages 子路径（`/MyBlogWeb/`），因此所有 URL 都需要拼接 base。`src/lib/url.ts` 是关键工具：

```ts
// 拼接导航/页面链接
export function withBase(href: string, base: string): string { ... }

// 处理 public/ 下的静态资源（PDF、图片）
export function assetUrl(path: string, base: string): string { ... }
```

**企业官网建议**：
- 如果用独立域名（`www.company.com`），`base: '/'`，可省略此工具
- 如果部署在子路径，**必须**用此工具，否则链接 404
- 无论如何，建议保留此工具函数，确保可移植性

### 8.2 Astro 配置

```js
export default defineConfig({
  site: 'https://www.company.com',   // 改为公司域名
  base: '/',                          // 独立域名用 '/'
  trailingSlash: 'ignore',
  markdown: {
    shikiConfig: { theme: 'github-light', wrap: true },  // 代码高亮
  },
});
```

### 8.3 构建与部署

```bash
npm run build      # 产物在 dist/
npm run preview    # 本地预览构建产物
```

**企业官网部署方案**：
- 静态托管：Vercel / Netlify / Cloudflare Pages（推荐，免费 + 自动 HTTPS + CDN）
- 对象存储：阿里云 OSS / 腾讯云 COS + CDN
- 传统服务器：Nginx 部署 `dist/`
