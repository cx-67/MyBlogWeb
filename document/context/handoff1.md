## 一、项目目标

基于 **Astro** 搭建个人技术博客 / 作品集站点，定位为「成馨 · 南京大学软件工程」的个人主页，核心叙事为：

- **用代码搭后端，用方法论讲方案**

站点需承载：

1. 个人简介（关于页 / 时间线）
2. 项目展示（projects 集合）
3. 文章 / 笔记输出（posts 集合）
4. （规划中）智能 Agent 助手 — 嵌在个人界面上，提供交互式问答 / 引导
5. 部署到 **GitHub Pages**，源码托管在 **GitHub 仓库**

## 三、设计规范（Design Spec）

### 3.1 视觉风格
- **风格定位**：温馨莫兰迪 + 简笔画卡通风格（非科技感）
- **情绪关键词**：温暖、柔和、可爱、治愈、低饱和

### 3.2 配色系统（莫兰迪色系）

| 色名 | Hex | 用途 |
|------|-----|------|
| 莫兰迪粉 | `#d7b3be` | 星星主色、点缀 |
| 灰蓝 | `#ABB5C0` | 月亮、冷调装饰 |
| 雾蓝 | `#ADC4D4` | 标签 tag-3 |
| 暖棕粉 | `#D5AAA7` | 强调色 accent |
| 暖黄 | `#EBE2AA` | 星星高光、标签 tag-5 |
| 薄荷 | `#B1DEDC` | 小云朵、标签 tag-2 |
| 奶油米 | `#F5EDE0` | hover 背景 |
| 拿铁 | `#E8DDD0` | 边框 hover |
| 鼠尾草绿 | `#C5C9B8` | 辅助绿调 |

**背景色**：`#FDFBF7`（米白温馨）
**文字色**：`#4A403A`（温暖深棕，替代冷灰黑）
**弱化文字**：`#7D756D` / `#A8A095`

### 3.3 标签统一配色（5 色莫兰迪胶囊）

| 类名 | 背景 | 文字 | 边框 | 感觉 |
|------|------|------|------|------|
| `.tag-1` | `#F5E8EC` | `#a87a88` | `#EBD5DC` | 莫兰迪粉 |
| `.tag-2` | `#E8F0E3` | `#7a9a6e` | `#D5E3CC` | 鼠尾草绿 |
| `.tag-3` | `#E5EDF2` | `#6b8fa0` | `#D0DEE8` | 雾蓝 |
| `.tag-4` | `#F0E8F2` | `#8a7a9a` | `#E0D5E5` | 淡紫灰 |
| `.tag-5` | `#F5F0E0` | `#9a8a5a` | `#EBE3CC` | 暖杏 |

> 所有标签统一为 **胶囊形**（`border-radius: 999px`），技术栈标签、项目标签、文章标签全部使用这 5 色循环。

### 3.4 字体
- **正文**：`Nunito Sans`（Google Fonts，圆润友好）
- **标题/Display**：`Varela Round`（Google Fonts，卡通感）
- **等宽**：`JetBrains Mono`（代码相关）

### 3.5 圆角与形状
- 小元素（标签）：`999px` 胶囊形
- 中等卡片：`16px`
- 大区块：`20px`
- 按钮：`999px` 胶囊形

### 3.6 动态效果
- **Hero 背景**：手绘星星 + 月亮 + 小云朵 Canvas 动画，缓慢飘动 + 闪烁
- **打字机**：主标题逐字打出，紫色光标闪烁
- **滚动渐入**：所有区块滚动进入视口时优雅浮现，支持错开延迟
- **卡片悬停**：顶部淡紫渐变光晕线条 + 阴影增强 + 上浮 3px

### 3.7 技术栈
- **框架**：Astro + TypeScript
- **样式**：自定义 CSS（CSS 变量驱动）
- **动画**：原生 JS + CSS（无外部动画库）
- **图标**：SVG / Lucide（不使用 emoji）

### 3.8 可访问性
- 支持 `prefers-reduced-motion`（系统减少动画偏好时自动关闭所有动画）
- 文字对比度 4.5:1 以上
- 所有可交互元素有 hover/focus 状态
