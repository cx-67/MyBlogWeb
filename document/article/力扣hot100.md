## 复习unordered\_map

**unordered\_map —— 映射（键值对）**

##### 常见场景

- 计数统计：元素出现次数（频率哈希表）。

- 缓存 / 记忆化：**DP 状态缓存**（如斐波那契、LRU 的辅助存储）。

- 配对 / 映射关系：**“两数之和”记录下标**、字符映射替换。

- 分组聚合：按某种特征归类（如字母异位词分组）。

##### 常用方法（刷题够用）

> 特别注意 `operator[]`：当键不存在时，会自动插入一个值初始化的键值对（`int` 为 0，`string` 为空串，`vector` 为空等）。这个特性在计数时极方便，但也可能无意中插入垃圾键，导致 `size()` 变化。若只想判断存在性，请用 `find` 或 `contains`。
> 
> 

##### 典型代码片段

```C++
// 1. 统计频率
vector<int> nums = {1,2,2,3};
unordered_map<int, int> freq;
for (int x : nums) {
    freq[x]++;   // 不存在时自动插入并初始化为0，然后++
}
// freq[2] == 2

// 2. 两数之和（返回下标）
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> mp;  // 值 -> 下标
    for (int i = 0; i < nums.size(); i++) {
        int left = target - nums[i];
        if (mp.contains(left)) { // 或 mp.find(left) != mp.end()
            return **{mp[left], i};**
        }
        mp[nums[i]] = i;//key:值，value:下标
    }
    return {};
}

// 3. 判断键是否存在（推荐写法）
if (mp.find(key) != mp.end()) {
    // 存在
}
// C++20 更优雅
if (mp.contains(key)) {
    // 存在
}
```

## 复习unordered\_set

**unordered\_set —— 集合（只存键，不存值）**

##### 常见场景

- 去重：数组或字符串中过滤重复元素。

- 快速存在性判断：查询某个元素是否出现过（如“两数之和”的补数查找）。

- 模拟数学集合：交集、并集、差集运算。

- 判重 \+ 循环检测：如链表找环（不过一般用 `set` 存节点指针）。

##### 常用方法（刷题够用）

##### 典型代码片段

```C++
*// 数组去重*
vector<int> nums = {1,2,2,3};
unordered_set<int> st(nums.begin(), nums.end());*// st = {1,2,3}*

*// 查找是否存在*
if (st.find(2) != st.end()) {
    cout << "存在" << endl;
}
```

```C++
    return last;
}
```

### 92\.反转链表2（✔）

**题述：**

给你单链表的头指针 `head` 和两个整数 `left` 和 `right` ，其中 `left <= right` 。请你反转从位置 `left` 到位置 `right` 的链表节点，返回 **反转后的链表** 。

思路：

**将（left, right\)部分的反转，转换成从（1，right\-left\)部分的反转**

题解：

```C++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
    ListNode* succ = nullptr;//后驱节点
public:
    ListNode* reverseN(ListNode* head, int n) {//反转以 head 为起点的 n 个节点，返回新的头结点
        if(n == 1) {
            //记录第n+1个节点
            succ = head->next;
            return head;
        }

        //以head为起点，反转前n-1个节点
        ListNode* last = reverseN(head->next, n-1);
        //此时head仍然为起点，建立反转关系 head<-head.next
        head->next->next = head;
        head->next = succ;//把head和后继连接
        return last;//此时last为整个链表的头节点
    }

    ListNode* reverseBetween(ListNode* head, int left, int right) {
        if(left == 1) {
            return reverseN(head, right);
        }
        head->next = reverseBetween(head->next, left-1, right-1);
        return head;
    }
};
```

### 21\.合并两个有序链表（✔）

**题述：**

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。 

思路：

1\.**哨兵技巧：创建一个哨兵节点，作为合并后的新链表头节点的前一个节点。**

2\.比较 list1和 list2的节点值，如果 list1的节点值小，则把 list1加到新链表的末尾，然后把 **list1替换成它的下一个节点**。如果 list2的节点值小则同理。

3\.如果两个节点值一样，那么把谁加到新链表的末尾都是一样的，不妨规定把list2加到新链表末尾。

4\.重复上述过程，直到其中一个链表为空。

5,循环结束后，其中一个链表可能还有剩余的节点，将剩余部分加到新链表的末尾。

6\.最后，返回新链表的头节点，即**哨兵节点的下一个节点**。

题解：

```C++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy;
        ListNode* cur = &dummy;// cur指向新链表末尾
        while(list1 && list2) {
            if(list1->val < list2->val) {
                cur->next = list1;
                list1 = list1->next;
            }else {
                cur->next = list2;
                list2 = list2->next;
            }
            cur = cur->next;//cur要时刻替换成新链表的末尾
        }

        cur->next = list1 ? list1 : list2;
        return dummy.next;
    }
};
```

### 25\.K个一组翻转链表（✔）

**题述：**

给你链表的头节点 `head` ，每 `k`* *个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k`* *的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

思路：

1\.使用哨兵模式

2\.统计节点个数，k个一组做翻转

```C++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        int n = 0;
        for(ListNode* cur = head; cur;cur = cur->next) {
            n++;
        }

        ListNode dummy(0, head);
        ListNode* p0 = &dummy;//指向新链表末尾
        ListNode* pre = nullptr;//指向已经倒转完的前继节点
        ListNode* cur = head;//指向当前准备倒转的节点

        //k个一组处理
        for(; n >= k; n -= k) {
            for(int i = 0; i < k; i++) {
                ListNode* nxt = cur->next;
                cur->next = pre;//倒转当前节点
                pre = cur;
                cur = nxt;
            }
            //实现p0的更换
            ListNode* nxt = p0->next;
            p0->next->next = cur;//实现pre.last->cur
            p0->next = pre;
            p0 = nxt;
        }
        return dummy.next;
    }
};
```

### 19\.删除链表的倒数第N个结点（✔）

**题述：**

给你一个链表，删除链表的倒数第 `n`* *个结点，并且返回链表的头结点。

思路：

1\.统计所有节点个数m

2\.找到需要删除的节点cur，以及其前继节点pre和后继节点nxt

3\.nxt = cur\-\>next, pre\-\>next = nxt，delete cur；

4\.使用哨兵模式，预防头节点被删除

题解：

```C++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);//可能会删除头节点,用哨兵节点简化代码
        ListNode* left = &dummy;
        ListNode* right = &dummy; 
        
        while(n--) {
            right = right->next;//右指针先走n步
        }

        while(right->next) {//r-l保持在n步,则当r走到末尾时,l是倒数n个节点
            left = left->next;
            right = right->next;
        }

        ListNode* nxt = left->next;
        left->next = left->next->next;
        **delete nxt;**
        return dummy.next;
    }
};
```

### 83\.删除排序链表中的重复数组（✔）

**题述:**

给定一个已排序的链表的头 `head` ， *删除所有重复的元素，使每个元素只出现一次* 。返回 *已排序的链表* 。

思路：

1\.若下一个节点和当前节点的val一样，则跳过下一个节点

2\.否则直接正常到下一个

题解：

```C++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {
        if(head == nullptr) return head;

        ListNode* cur = head;
        while(cur->next) {
            if(cur->next->val == cur->val) {
                cur->next = cur->next->next;
            }else {
                cur = cur->next;
            }
        }
        return head;
    }
};
```

### 82\.删除排序链表中的重复数组2（✔）

**题述：**

给定一个**已排序**的链表的头 `head` ， *删除原始链表中所有重复数字的节点，只留下不同的数字* 。返回 ***已排序的链表*** 。

思路：

1\.哨兵节点dummy: 头节点会因题目需要而被删除或者修改，这个时候定义一个首元节点，就可以通过首元节点来访问整个链表

2\.删除所有重复数字的节点: while\(cur\-\>next \&\& cur\-\>next\-\>val == val\) 

题解：

```C++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {
        ListNode dummy(0, head);
        auto cur = &dummy;
        while(cur->next && cur->next->next) {
            int val = cur->next->val;
            if(cur->next->next->val == val) { //后两个节点值相同
                //值等于val的全部删除
                while(cur->next && cur->next->val == val) {
                    cur->next = cur->next->next;
                }
            }else {
                cur = cur->next;
            }
        }
        return dummy.next;
    }
};
```

### 146\.LRU缓存（✔）

**题述：**

请你设计并实现一个满足  [LRU \(最近最少使用\) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存

- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。

- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

思路：
1\.使用标准库

2\.哈希表：储存记录，方便用key直接查询

3\.手写**双向链表**：`list<pair<int,int>>` \+ `unordered_map`

```C++
class LRUCache {
private:
    int cap;
    list<pair<int, int>> cache; // pair保存的是key和value
    unordered_map<int, list<pair<int, int>>::iterator> map;//key->链表节点迭代器的映射

public:
    LRUCache(int capacity) : cap(capacity){
    }
    
    int get(int key) {
        if(map.find(key) == map.end()) return -1;//key不在迭代器里
        auto key_value = *map[key];//在迭代器里
        // 把这本书从书堆cache中抽出来，放到最上面（cache.begin()）
        cache.erase(map[key]);
        cache.push_front(key_value);//key = 0，value = kv
        map[key] = cache.begin();
        return key_value.second;//返回value
    }
    
    void put(int key, int value) {
        if(map.find(key) == map.end()) {//没有这本书
            if(cache.size() == cap) {//判断书堆是否满了
                //去掉最下面一本书
                map.erase(cache.back().first);
                cache.pop_back();
            }
        }else {
            cache.erase(map[key]);//删除原来的值
        }
        //把书放到最上面，并重置值
        cache.push_front({key, value});
        map[key] = cache.begin();
    }

};

/**
 * Your LRUCache object will be instantiated and called as such:
 * LRUCache* obj = new LRUCache(capacity);
 * int param_1 = obj->get(key);
 * obj->put(key,value);
 */
```

### 144\.二叉树的前序遍历（✔）

题述：给你二叉树的根节点 `root` ，返回它节点值的 **前序*** *遍历。

思路：

**递归：先树根，然后左子树，然后右子树。每棵子树递归。**

1\.**确定递归函数的参数和返回值**：因为要打印出前序遍历节点的数值，所以参数里需要传入vector在放节点的数值，除了这一点就不需要在处理什么数据了也不需要有返回值，所以递归函数返回类型就是void，代码如下：

```C++
void traversal(TreeNode* cur, vector<int>& vec)
```

2\.**确定终止条件**：当前遍历的节点为空了，本层递归就结束，直接return，代码如下：

```C++
if (cur == NULL) return;
```

3\.**确定单层递归的逻辑**：前序遍历是**中左右**的循序，所以在单层递归的逻辑，是要先取中节点的数值，代码如下：

```C++
vec.push_back(cur->val);    // 中
traversal(cur->left, vec);  // 左
traversal(cur->right, vec); // 右
```

题解：

```C++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
```

### 102\.二叉树的层序遍历（✔）

**题述：**

给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。（即逐层地，从左到右访问所有节点）。

思路：

1\.BFS（广度优先搜索）：解决**层序遍历**、**最短路径**问题。使用**队列**（先进先出）实现。

2\.实现：BFS 循环： 当队列 queue 为空时跳出。

1. 新建一个临时列表 tmp ，用于存储**当前层打印结果**。

2. 当前层打印循环： 循环次数为**当前层节点数**（即队列 queue 长度）。

    1. 出队： 队首元素出队，记为 node。

    2. 打印： 将 node\.val 添加至 tmp 尾部。

    3. 添加子节点： 若 node 的左（右）子节点不为空，则将左（右）子节点加入队列 queue 。

3. 将当前层结果 tmp 添加入 res 。

题解：

```C++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        queue<TreeNode*> q;//记录等待查询的节点队列
        vector<vector<int>> res;//记录答案

        if(root != nullptr) q.push(root);
        while(!q.empty()) {
            vector<int> tmp;
            for(int i = q.size(); i > 0; --i) {//遍历当前队列里的节点
                root = q.front();
                **q.pop();**//root已被查询出列
                tmp.push_back(root->val);
                if (root->left != nullptr) q.push(root->left);
                if (root->right != nullptr) q.push(root->right);
            }
            res.push_back(tmp);//将本层节点加入答案
        }

        return res;

    }
};
```

### 124\.二叉树的最大路径和（✔）

**题述：**

二叉树中的** 路径** 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次** 。该路径** 至少包含一个 **节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

**关键概念：**

**链**：从下面的某个节点（不一定是叶子）到当前节点的路径。把这条链的节点值之和，作为 *dfs* 的返回值。

**直径**：等价于由两条（或者一条）链拼成的路径。我们枚举每个 *node*，假设直径在这里「**拐弯**」，也就是计算由左右两条从下面的某个节点（**不一定是叶子**）到 *node* 的链的节点值之和，去更新答案的最大值。

思路：

1\.树形直径**dp（动态规划）**:枚举all**拐弯点**node，记录左右**子链**的**最大和**

2\.DFS 返回的是**链**的节点值之和，不是**直径**的节点值之和。

题解：

```C++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int ans = INT_MIN;

    int dfs(TreeNode *node) {
        if(node == nullptr) return 0;
        int left = dfs(node->left);
        int right = dfs(node->right);
        //若为负数则放弃选择分支
        left = max(left, 0);
        right = max(right, 0);
        //递归进行更新
        ans = max(ans, node->val + left + right);

        return node->val + max(left, right);//记录左右子链最大和
    }

    int maxPathSum(TreeNode* root) {
        dfs(root);
        return ans;
        
    }
};
```

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

思路：（根本没用到堆）

1\.**桶排序: **注意到\[\-10000,10000\]的较小数据范围，可以采用类似桶排序的思想解决。（最原始的方法）

2\.实现：只需要定义一个**足够覆盖值域**的数组，用于**填充每个值出现的次数**，然后从高到低遍历，不断将次数累加，当**次数\>=k**时意味着**这一位数值就是答案**。

3\.注意到数值会出现负数，进行**相应的偏移**即可。

4\.复杂度：O（n\)

题解：

```C++
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        //barrel:存储**每个数值出现的频次**
        vector<int> barrel(20005, 0); //正负各10000
        for(int x : nums) {//数组下标不能为负数
            barrel[x + 1e4]++;//将可能为负的数值映射到非负下标
        }

        for(int i = 20004; i >= 0; i--) {
            k -= barrel[i];//每经过一个桶，就减去该数值的个数
            //当 k <= 0 时，说明第 K 大的元素落在当前桶对应的数值上
            if(k <= 0) return i - 1e4;//最后返回时需要**减去偏移量**还原真实值
        }

        return 0;
    }
};
```

**1\.DFS 和回溯算法区别**

### 46\.全排列（✔）

**题述：**

给定一个**不含重复数字**的数组 `nums` ，返回其*所有可能的全排列* 。你可以**按任意顺序**返回答案。

思路：

**递归解析：**

1\.**终止条件**： 当`start = len(nums) - 1`时，代表所有位已固定（最后一位只有 1 种情况），则将当前组合`nums`转化为数组并加入`res`，并返回。

2\.**递推参数**： 当前固定位 `start`。

**3\.递推工作**： 将第`start`位元素与`i ∈（start, len(nums)]` 元素分别交换，并进入下层递归。

1. **固定元素：** 将元素`nums[i]`和`nums[start]`交换，即固定`nums[i]`为当前位元素。

2. **开启下层递归：** 调用`dfs(start + 1)`，即开始固定第`start + 1`个元素。

3. **还原交换：** 将元素`nums[i]`和`nums[start]`交换（还原之前的交换）。

题解：

```C++
class Solution {
public:
    vector<vector<int>> res;
    void dfs(int start, vector<int>& nums) {//start指从nums的start下标开始,变更后续的元素,start前不变
        if(start == nums.size()-1) {
            res.push_back(nums);
            return;
        }

        for(int i = start; i < nums.size(); i++) {
            //只变动start位置,依次和其后面的元素互换
            swap(nums[start], nums[i]);
            //固定nums[i]（互换后的nums)
            dfs(start + 1, nums);
            //引用传值,前一轮变动后需要恢复(将start在下一个循环里维持在可替换的位置)
            swap(nums[start], nums[i]);
        }
    }

    vector<vector<int>> permute(vector<int>& nums) {
        dfs(0, nums);
        return res;
    }
};
```

### 47\.全排列2（✔）

**题述：**

给定一个可包含重复数字的序列 `nums` ，***按任意顺序*** 返回所有不重复的全排列。

思路：

**1\.剪枝**：**即遇到重复元素时不交换，直接跳过**

2\.递归：

1. **终止条件：** 当 `x = nums.size() - 1` 时，代表所有位已固定（最后一位只有 1 种情况），则将当前组合 `nums` 转化为数组并加入 `res` ，并返回。

2. **递推参数：** 当前固定位 x 。

3. **递推工作：** 初始化一个 **Set** ，用于排除重复的元素；将第 x 位元素与 i ∈ \[x, nums\.size\(\)\] 元素分别交换，并进入下层递归。

    1. 剪枝： 若 nums\[i\] 在 Set 中，代表其是重复元素，因此 “剪枝” 。

    2. 将 nums\[i\] 加入 Set ，以便之后遇到重复元素时剪枝。

    3. 固定元素： 将元素 nums\[i\] 和 nums\[x\] 交换，即固定 nums\[i\] 为当前位元素。

    4. 开启下层递归： 调用 dfs\(x \+ 1\) ，即开始固定第 x \+ 1 个元素。

    5. 还原交换： 将元素 nums\[i\] 和 nums\[x\] 交换（还原之前的交换）。

题解：

```C++
class Solution {
public:
    vector<vector<int>> permuteUnique(vector<int>& nums) {
        dfs(nums, 0);
        return res;
    }

private:
    vector<vector<int>> res;
    void dfs(vector<int> nums, int x) {
        if(x == nums.size() - 1) {
            res.push_back(nums);
            return;
        }
        set<int> s;
        for(int i = x; i < nums.size(); i++) {
            if(s.find(nums[i]) != s.end()) { //nums[i]在集合里出现
                continue;//剪枝
            }
            s.insert(nums[i]);
            swap(nums[i], nums[x]);
            dfs(nums, x+1);
            swap(nums[i], nums[x]);//回溯到原数组
        }
    }
};

```

```C++
class Solution {
```

### 90\.子集2（✔）

**题述：**

给你一个整数数组 `nums` ，其中可能包含重复元素，请你返回该数组所有可能的 子集（幂集）。

解集 **不能** 包含重复的子集。返回的解集中，子集可以按 **任意顺序** 排列。

思路：

1\.选或**不选**：在**不选** nums\[i\] 时，要**跳过后续所有等于** nums\[i\] 的数。如果不跳过这些数，比如 nums\[i\]=nums\[i\+1\]=2，那么「选第一个 2 不选第二个 2」和「不选第一个 2 选第二个 2」这两种情况都相当于「选了一个 2」，这就重复了。

2\.排序：为了方便跳过相同元素，在递归前，把 nums 排序（从小到大或者从大到小都可以）。

题解：

```C++
class Solution {
public:
    vector<vector<int>> ans;
    vector<int> path;
    void dfs(vector<int>& nums, vector<int>& path, int i) {
        if(i == nums.size()) {
            ans.push_back(path);
            return;
        }
        int x = nums[i];

        //选
        path.push_back(x);
        dfs(nums, path, i+1);
        path.pop_back();

        //不选
        i++;
        while(i < nums.size() && nums[i] == x) {//跳过后续所有相同的数（都不选)
            //注意要先判断边界情况,i++时并没有保证此时i可能已经等于n,则此时nums[i]访问数组越界
            i++;
        }
        dfs(nums, path, i);
    }

    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        dfs(nums, path, 0);
        return ans;
    }
};
```

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。 

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

思路：

1\.选或不选：用 dfs\(i,left\) 来回溯，设当前枚举到 candidates\[i\]，**剩余要选的元素之和**为 **left**，按照选或不选分类讨论：

- 不选 candidates\[i\]：递归到 dfs\(i\+1,left\)。

- 选 candidates\[i\]：递归到 dfs\(i,left−candidates\[i\]\)。注意 i 不变，表示在下次递归中可以继续选 candidates\[i\]。

2\.如果递归中发现 **left=0** 则说明找到了一个合法组合，**复制一份 path 加入答案**。

3\.递归边界：如果 i=n 或者 left\<0 则返回。

4\.递归入口：dfs\(0,target\)。

题解：

```C++
class Solution {
public:
    vector<vector<int>> ans;
    vector<int> path; // 记录一种符合target的组合

    void dfs(vector<int>& candidates, vector<int>& path, int i, int left) {
        if(left == 0) {
            ans.push_back(path);
            return;
        }

        if(left < 0 || i == candidates.size()) {
            return ;
        }

        //不选
        dfs(candidates, path, i+1, left);

        //选，注意i不变，下一次还能选择candidates[i]
        path.push_back(candidates[i]);
        dfs(candidates, path, i, left - candidates[i]);
        path.pop_back();//恢复
    }

    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        dfs(candidates, path, 0, target);
        return ans;
    }
};
```

```C++
class Solution {
public:
```

```C++
        if (n == 0) {
            return 0;
        }

        leftMax[0] = height[0];
        for (int i = **1**; i < n; ++i) {
            leftMax[i] = max(leftMax[**i - 1]**, height[i]);

            rightMax[i] = max(rightMax[**i + 1**], height[i]);

            ans += min(leftMax[i], rightMax[i]) - height[i];
            //i 处能接的雨水量等于i处的水能到达的最大高度减去 height[i]
            //i处的水能到达的最大高度：左右两边最大高度的最小值
        }
        return ans;
    }
```

### 560\.和为K的子数组

**题述：**

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 *该数组中和为 **`k`**** ****的子数组的个数 *。

思路: **（前缀和\+哈希表）**

1\.定义 `prefix[i]` 为 `nums[0] + ... + nums[i-1]`（前 i 个元素的和）。

2\.那么以j为开头的子数组 `nums[j..i-1]` 的和 = `prefix[i] - prefix[j]`。

3\.将`prefix[i] - prefix[j] == k` → `prefix[j] == prefix[i] - k`

**4\.**遍历数组时，用一个哈希表记录之前每个前缀和出现的次数，看看当前 `prefix[i] - k` 出现过几次，每次出现就对应一个起点 `j`，答案就加上那个次数。

5\.初始 `prefix[0] = 0` 出现一次。

题解：

```C++
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> preSumCount; // 存储前缀和出现的次数
        preSumCount[0] = 1; // 前缀和为0的情况（空子数组）
        int preSum = 0;
        int ans = 0;

        for(int num : nums) {
            preSum += num; //记录当前的前缀和

            if(preSumCount.count(preSum - k)) {//查找之前是否有前缀和为 prefixSum - k 的位置
                ans += preSumCount[preSum - k];
            }

            preSumCount[preSum]++;
        }
        return ans;
    }
};
```

### 239\.滑动窗口的最大值

**题述**：

给你一个整数数组 `nums`，有一个大小为 `k`* *的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 *滑动窗口中的最大值 *。

思路：

1\.最暴力，不考虑时间复杂度：每次循环窗口找最大  O\(n^2\)复杂度

2\.使用**单调队列（双端队列）**：保持记录的最大值保持在队首且队列单调递减。

单调队列套路

1. 右边入（元素进入**队尾**，同时维护队列**单调性**）

2. 左边出（元素离开**队首**）

3. 记录/维护答案（根据**队首**）

3\.整体解题思路：

1. 右入：队列不为空且队列最后一个数\<=nums\[i\]，把队尾弹出，插入下标i

2. 左出：如果队首下标不在窗口范围内，则弹出

3. 记录答案：当队列\>=k时（一个窗口），队首就是最大值

题解：

```C++
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> ans(n - k + 1);
        deque<int> q;//双端队列

        for(int i = 0; i < n; i++) {
            //1.右边入
            while(!q.empty() && nums[q.back()] <= nums[i]) {
                q.pop_back(); //维护q的单调性，保持严格递减
            }
            q.push_back(i);//把i插入队列
            //2.左边出
            int left = i - k + 1;
            if(q.front() <left) {
                q.pop_front();//队首离开窗口，队列不再记录
            }
            //3.记录答案
            if(left >= 0) {//在窗口左端点处记录答案
                ans[left] = nums[q.front()];//队首即为答案
            }
        }
        return ans;
    }
};
```

**题述：**

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 **子串，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串* *`""`。

2\.【涵盖】：s子串的每个字母出现次数\>=t中每个字母出现次数

3\.枚举 s 子串的右端点 right，如果子串涵盖 t，就不断右移左端点 left 直到不涵盖为止。在移动过程中更新最短子串的左右端点。

4\.出现字母次数统计\-\>哈希表cnt\[26\]记录（注意：仅有大/小写可以），若是大小写混合，则用cnt\[128\]，ASCll值作为下标更佳。

题解：

```C++
class Solution {
    bool is_covered**(int cnt_s[], int cnt_t[]**) {
        for(int i = 'A'; i <= 'Z'; i++) {
            if(cnt_s[i] < cnt_t[i]) return false;
        }

        for(int i = 'a'; i <= 'z'; i++) {
            if(cnt_s[i] < cnt_t[i]) return false;
        }

        return true;
    }

public:
    string minWindow(string s, string t) {
        int m = s.size();
        int n = t.size();

        if(n > m) return "";

        **int cnt_s[128]{};**
**        int cnt_t[128]{};**

        for(char c : t) {
            cnt_t[c]++;
        }

        int ansLeft = -1, ansRight = m;
        int left = 0;

        for(int right = 0; right < m; right++) {//移动子串左右端点
            cnt_s[s[right]]++;//右入：右端点入子串
            while(is_covered(cnt_s, cnt_t)) {//如果hangai
                if(right - left < ansRight - ansLeft) {//如果当前子串更小
                    ansLeft = left;
                    ansRight = right;
                }
                cnt_s[s[left]]--;//左出：左端点出子串
                left++;
            }
        }

        if(ansLeft < 0) return "";
        return s.substr(ansLeft, **ansRight - ansLeft + 1)**;//**substr(起点，长度)**
    }
};
```

```C++
class Solution {

        int min_pre_sum = 0;//最小前缀和
        int pre_sum = 0;//前缀和

        for(int x : nums) {
            pre_sum += x;
            ans = max(ans, pre_sum - min_pre_sum);
            min_pre_sum = min(min_pre_sum, pre_sum);
        }

        return ans;
    }
};
```

1\.使用前后缀乘积：前缀积\*后缀积=除自身外乘积

2\.前缀积：pre\[i\] = pre\[i\-1\]\*nums\[i\-1\]

3\.后缀积：suf\[i\] = suf\[i\+1\]\*nums\[i\+1\]

题解：

```C++
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n);//pre*suf
        vector<int> pre(n, 1);//pre[i] = pre[i-1]*nums[i-1]
        vector<int> suf(n, 1);//suf[i] = suf[i+1]*nums[i+1]

        for(int i = 1; i < n; i++) {
            pre[i] = pre[i-1] *nums[i-1];
        }

        for(int i = n - 2; i >= 0; i--) {
            suf[i] = suf[i+1] *nums[i+1];
        }

        for(int i = 0; i < n; i++) {
            ans[i] = pre[i] * suf[i];
        }

        return ans;
    }
};
```

### 41\.缺失的第一个正数

**题述：**

给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

思路：

1\.找座位：座位与目前坐的同学的学号是否匹配\(学号区间：\[1, n\]）

2\.若都匹配，则答案为n\+1

3\.若有不匹配，则答案为第一个不匹配的座位编号

4\.nums\[nums\[i\] \- 1\] \!= nums\[i\]

翻译：

当前数字是 nums\[i\]

它应该坐的位置是 nums\[i\] \- 1

去看那个位置上的数字：nums\[ nums\[i\] \- 1 \]

判断：正确位置上的数字 == 当前数字吗？

如果 \!= → 说明坐错了，要交换

如果 == → 说明已经坐对了，不用动

题解：

```C++
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();
        for(int i = 0; i < n; i++) {
            // 如果当前学生的学号在 [1,n] 中，但（真身）没有坐在正确的座位上
            while(nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int j = nums[i] - 1; //记录i对应的学号(数组下标要-1)
                swap(nums[i], nums[j]);
            }
        }

        // 找第一个学号与座位编号不匹配的学生
        for(int i = 0; i < n; i++) {
            if(nums[i] != i + 1) {//学号与座位编号不符
                return i+1;//返回座位编号
            }
        }
        //所有同学坐在正确的座位上
        return n+1;
    }
};
```

### 73\.矩阵置0

**题述：**

给定一个 *`m`*` x `*`n`* 的矩阵，如果一个元素为 **0 **，则将其所在行和列的所有元素都设为 **0** 。请使用 [**原地**](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95) 算法**。**

思路：

1\.注意：只能动初始值就为0的行与列，修改后的0不能修改对应行与列

2\.使用flag：若flag\[i\]\[j\]==1，则说明最后要替换成0

3\.实现：第一次遍历，使用函数，判断到0，则调用函数，把所在的行与列的flag置为1，最后遍历查询flag

题解：

```Java
class Solution {
public:
    void setFlags(int x, int y, vector<vector<int>>& flag) {
        int m = flag.size(), n = flag[0].size();
        for(int i = 0; i < m; i++) {//将所在列flag置1
            flag[i][y] = 1;
        }

        for(int j = 0; j < n; j++) {//将所在行flag置1
            flag[x][j] = 1;
        }
    }

    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<vector<int>> flag(m, vector<int>(n, 0));//用来判断最后是否替换成0

        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if(matrix[i][j] == 0) setFlags(i, j, flag);
            }
        }

        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if(flag[i][j] == 1) matrix[i][j] = 0;
            }
        }
    }
};
```

### 54\.螺旋矩阵

**题述：**

给你一个 `m` 行 `n` 列的矩阵 `matrix` ，请按照 **顺时针螺旋顺序** ，返回矩阵中的所有元素。

思路：

1\.顺时针读取：设定读取方向direct = \(direct\+1\) % 4：direct = 0\(往左）\-\>1\(往下）\-\>2（往右）\-\>3（往上）

2\.把读取过的数标记为INT\_MAX，用于区分

题解：

```C++
class Solution {
public:
    static constexpr int DIRS[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}}; // 顺时针螺旋顺序：右下左上,前项代表x坐标变化,后项代表y坐标变化

    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();

        vector<int> ans(m * n);

        int i = 0, j = 0, di = 0;

        for(int k = 0; k < m*n; k++) {
            ans[k] = matrix[i][j];
            matrix[i][j] = INT_MAX;// 标记，表示已经访问过（已经加入过答案）
            
            int x = i + DIRS[di][0];
            int y = j + DIRS[di][1];
            // 如果下一步所在的位置(x, y) 出界或者已经访问过
            if(x < 0 || x >= m || y < 0 || y >= n || matrix[x][y] == INT_MAX) {
                di = (di + 1) % 4;// 右转 90°
            }

            i += DIRS[di][0];
            j += DIRS[di][1];
        }
        
        return ans;
    }
};
```

### 48\.旋转图像

**题述：**

给定一个 *n *× *n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在[** 原地**](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95) 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要 **使用另一个矩阵来旋转图像。

思路：

**两次翻转等于一次旋转**

\(i,j\)→\(j,n−1−i\) 可以通过两次翻转操作得到：

\(i,j\) ——\>\(j,i\) ——\> \(j,n−1−i\)

1. **转置：**把矩阵按照主对角线翻转，位于 \(i,j\) 的元素去到 \(j,i\)。

2. **行翻转：**把每一行翻转，位于 \(j,i\) 的元素去到 \(j,n−1−i\)。

题解：

```C++
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) { // 遍历对角线上方元素，做转置
                //swap的作用对象是双向的
                swap(matrix[i][j], matrix[j][i]);
            }
            ranges::reverse(matrix[i]); // 行翻转
        }
    }
};
```
